External DSL Modes

The external DSL supports multiple parser modes designed for specific task styles. Each mode can be explicitly selected using a #! header.

Mode Syntactic Style Primary Feature
#!declarative Infix notation Explicit ask queries and const declarations
#!prolog Logic programming Traditional head :- body. rules and ?- queries
#!flix Datalog-like Fact-first definitions with query execution
#!cypher Graph-like MATCH patterns with WHERE filtering and RETURN
